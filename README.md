# 在办 · PRJM

一个本地优先的日常项目追踪器。选择一个工作目录，挑出正在进行的项目文件夹，记录进展、固定重点文件，然后从一个总览里继续下一件事。

跨平台、无需账号、无需后端服务。Windows / macOS 使用最新版 Chrome 或 Edge；Android 使用 Chrome 132 及以上版本。

## 本地运行

```bash
npm install
npm run dev
```

打开终端中显示的地址（默认 `http://localhost:5173`）。

生产构建与预览：

```bash
npm run build
npm run preview
```

`dist/` 是完整的静态站点，部署到任意支持 HTTPS 的静态托管即可通过浏览器安装到桌面或 Android 主屏幕。文件系统能力要求 HTTPS 或 localhost，因此请部署在站点根路径下。

## 使用

1. **选择工作目录**：应用会扫描该目录下的一级文件夹。
2. **添加进行中的项目**：勾选需要跟踪的项目文件夹。可以随时继续添加。
3. **查看与记录**：单击项目行打开笔记面板；按 `⌘/Ctrl + Enter` 快速记录一条进展。
4. **进入项目文件夹**：双击项目，或点击行尾的文件夹按钮。在文件浏览器里双击文件可预览。
5. **固定重点文件**：在项目文件夹或笔记面板里点击文件右侧的星标，文件会显示在总览列表上，单击即可预览。
6. **停止跟踪**：只从总览中移除，不会删除文件夹或任何记录。

工作区菜单（左上角目录名）可以重新读取磁盘、切换工作目录、导出全部记录，以及安装为桌面应用（浏览器支持时）。

## 数据保存

所有内容保存在你选择的目录里，不会上传：

- 工作区索引：`<工作目录>/.prjm/workspace.json`
- 项目记录：`<项目文件夹>/.prjm/project.json`

项目记录包含时间戳笔记、重点文件的相对路径和引用信息。删除某个项目里的 `.prjm` 目录会移除该项目笔记，但不会影响项目里的其他文件；停止跟踪只会修改工作区索引。

浏览器只保留工作目录的访问凭据，不保留笔记副本。换设备或清除浏览器站点数据后，重新选择工作目录即可恢复。

## 技术栈

- React 19 + TypeScript + Vite
- File System Access API（本地目录读写）
- IndexedDB（保存目录访问凭据）
- 自包含 PWA / Service Worker（离线打开、安装到桌面）

## 脚本

```bash
npm run dev        # 开发服务器
npm run build      # 类型检查并生成 dist
npm run preview    # 预览生产构建
npm run typecheck  # 仅类型检查
```

应用图标由 `scripts/generate-icons.ps1` 生成（Windows / PowerShell）。
